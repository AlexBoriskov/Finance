ДЕЛА И ДЕНЬГИ — приложение для телефона
========================================

Что внутри
  index.html               — само приложение (один файл)
  manifest.webmanifest     — описание для установки на экран «Домой»
  sw.js                    — работа без интернета и обновление версий
  icon-*.png, apple-touch-icon.png — иконки
  fonts/                   — шрифт Inter для оформления (4 файла). Папку
                             нужно загружать вместе с остальными файлами.

Как поставить на телефон
  Приложение нужно открыть по ссылке (https). Из файла напрямую оно
  тоже запускается, но браузер может очистить данные, а на экран
  «Домой» такое не устанавливается.

  1. Распакуйте архив и выложите файлы на бесплатный хостинг
     (GitHub Pages: репозиторий → uploading an existing file →
     перетащить файлы → Commit changes → Settings → Pages →
     Deploy from a branch → main / root).
  2. Откройте ссылку на телефоне.
  3. Android (Chrome): меню ⋮ → «Установить приложение».
     iPhone (Safari): «Поделиться» → «На экран Домой».

Как обновить приложение после новой версии
  1. Распакуйте новый архив.
  2. В репозитории на GitHub: Add file → Upload files → перетащите ВСЕ
     файлы и папку fonts (обязательно index.html и sw.js) → Commit changes.
     Файлы с теми же именами заменятся.
  3. Подождите минуту-две и откройте приложение на телефоне. Новая
     версия подхватится сама, при необходимости закройте и откройте
     приложение ещё раз.
  Данные при этом не пропадают: они лежат в телефоне, а не на сайте.

О названии
  Приложение переименовано в «Дела и деньги». У уже установленного
  приложения название под значком может остаться прежним. Если хотите
  обновить: сохраните копию данных (Ещё → Данные), удалите значок,
  установите приложение заново и восстановите данные из копии.

Где хранятся данные
  В localStorage браузера на этом устройстве. Никуда не отправляются.
  Данные привязаны к адресу сайта и к браузеру: если сменить адрес или
  браузер, они не перенесутся сами — сделайте копию (Ещё → Данные →
  Сохранить копию) и восстановите её на новом месте.
  Делайте копию раз в месяц: браузер может очистить память сайта.
  Приложение напомнит.

Оформление
  Светлая и тёмная тема включаются сами по настройке телефона. «Сегодня»
  собрано из блоков: баланс с ближайшим платежом, кольца дел и привычек,
  карточка «Скоро» (события и дни рождения). Остальные разделы — на
  карточках. Внизу плавающая панель разделов.

Навигация
  Внизу пять разделов: Сегодня, Календарь, Дела, Деньги, Ещё.
  «Деньги» — Обзор, Операции, Планы, Долги/цели. «Дела» — Дела, Проекты,
  Привычки. «Календарь» — Месяц, Дни рождения. Переключатель находится
  вверху раздела. «Ещё» — настройки, лимиты, календарь телефона,
  категории, теги, копии данных. Повторное нажатие на активную вкладку возвращает в начало
  раздела (например, со страницы проекта в список).

Сегодня
  Сверху блоки: свободные деньги с ближайшим платежом, кольца дел и
  привычек, карточка с ближайшими делами со временем и днями рождения:
  подписи «Сегодня» и «Дальше» (только если обе группы непустые),
  «Дальше» идёт от ближайшей даты к дальней. Карточка баланса — просто
  цифры, без кнопок: добавить трату можно только одним способом —
  переключателем «Дело / Трата» чуть ниже.
  Дальше идёт этот переключатель со строкой быстрого ввода (см.
  «Быстрый ввод»), привычки, свёрнутый по умолчанию блок «Дела на
  сегодня» (просроченные и сегодняшние, счётчик «осталось X из Y» в
  заголовке), следующие шаги проектов, «Деньги на нынешний месяц» (в
  него же вложены и «Планы без срока» — см. ниже) и «Сделано сегодня».
  Пустых блоков на экране нет.
  «Перенести несделанное на завтра» — внутри развёрнутого блока дел,
  переносит сразу и предлагает «Отменить».

Деньги на нынешний месяц (на «Сегодня»)
  Раскрывающийся блок. В свёрнутом виде: сколько пунктов и сколько
  денег останется к концу месяца. В раскрытом: все приходы и расходы,
  запланированные на месяц (планы, повторяющиеся платежи, платежи по
  долгам, возвраты долгов, записи на будущие даты), включая просроченные,
  затем лимиты месяца («осталось X из Y», если лимиты заданы) и итог:
  приходы по плану, расходы по плану, заложено по лимитам и «К концу
  месяца».
  «К концу месяца» = свободные деньги сейчас + приходы − расходы −
  остаток лимитов, который ещё не занят запланированными тратами
  (берётся остаток общего лимита, а если его нет — остатки лимитов
  категорий).
  Внутри того же блока, ниже итога — «Планы без срока»: показываются,
  только если к концу месяца остаются деньги. В списке те планы без
  даты, на которые хватает (в порядке добавления, пока остаток
  позволяет). Кнопка «в этом месяце» ставит плану последний день
  месяца, и он переезжает в список выше. Раньше это были два отдельных
  блока на «Сегодня» — теперь один, со своим счётчиком в заголовке.

Дела
  Быстрый ввод: впишите дело и нажмите Enter, срок выбирается кнопками
  «Сегодня / Завтра / Без срока». Полная форма (кнопка «Дело»): срок,
  проект, повтор (каждый день, неделю, месяц, год), заметка.
  Повторяющееся дело при выполнении переносится на следующую дату,
  отметку можно отменить в блоке «Сделано сегодня».
  Список сгруппирован по срокам: Просрочено, Сегодня, Завтра, На неделе,
  Позже, Без срока. Можно отфильтровать по проекту.

Проекты (Дела → «Проекты»)
  Проект: название, цель, срок и шаги. Шаги упорядочиваются кнопками
  ▲ ▼. Первый невыполненный шаг — «следующий шаг»: только он
  показывается в «Сегодня» (или нажмите «на сегодня»). Когда все шаги
  выполнены, предлагается завершить проект. Проект можно поставить на
  паузу. При удалении проекта удаляются и его шаги.

Привычки (Дела → «Привычки»)
  Привычка бывает двух видов: «Да / нет» (например, зарядка) и
  «Счётчик» (например, вода: цель 8 стаканов в день, единица
  «стаканов», шаг одного нажатия «＋» можно задать: 5 минут чтения и т. п.).
  Можно выбрать дни недели (например, только по будням).
  На «Сегодня» показаны привычки, запланированные на этот день: у
  счётчика кнопки «−» и «＋» и полоска прогресса, у «Да / нет» галочка.
  Когда цель дня выполнена, приложение сообщает об этом.
  Серия — сколько запланированных дней подряд цель выполнена. Сегодняшний
  ещё не выполненный день серию не обрывает, а дни, когда привычка не
  запланирована, пропускаются. Есть также лучшая серия, процент за 30
  дней и всего выполненных дней.
  Страница привычки: история за пять недель. Нажмите на день, чтобы
  исправить отметку задним числом. Привычку можно отправить в архив
  (история сохранится) или удалить (история удалится). Есть шаблоны:
  вода, зарядка, чтение.

Категории дел (Дела → форма дела, или Ещё → «Категории дел», свёрнуто
по умолчанию)
  Готовые категории: Работа, Дом, Личное — можно переименовать, сменить
  цвет, удалить (если категория не используется) или добавить свою прямо
  из формы дела кнопкой «＋ Новая». В строке быстрого ввода дела категория
  указывается через @, например «сходить в химчистку @дом». На вкладке
  «Дела» есть фильтр по категории (и отдельно по проекту). Категория
  необязательна.

Календарь
  Дело — это и обычная задача, и то, что раньше было «событием»: у него
  есть необязательные время и место (Ещё → форма дела → «Время», внутри
  «Подробнее» → «Место»). Отдельной сущности «Событие» больше нет.
  Месяц с точками: день рождения, дело (одна точка и для обычных дел, и
  для дел со временем), срок проекта, деньги. Нажмите на день — внизу
  список того, что на него приходится (дела со временем идут первыми,
  по времени), и строка быстрого добавления дела на эту дату — она
  тоже распознаёт время и остальные слова (см. «Быстрый ввод»).
  Повторяющееся дело показывается на календаре только на своей текущей
  дате, а не на всех будущих датах повтора — это сознательное упрощение
  по сравнению с прежними «событиями»: как только дело выполнено, оно
  само переходит на следующую дату повтора.
  Google Календарь и «Файл для календаря» доступны у любого дела со
  сроком, как раньше у событий.

Дни рождения (Календарь → «Дни рождения»)
  У каждого: день и месяц, год рождения (необязательно, тогда
  считается возраст), за сколько дней показывать в «Сегодня»
  (3, 7, 14 или 30), бюджет на подарок, заметка «как празднуем».
  Страница человека: идеи подарков с ценами и пометкой «куплено»,
  суммы (бюджет, куплено, идеи). Кнопка «Запланировать расход на
  подарок» создаёт план за 3 дня до праздника в категории «Подарки»,
  он виден в «Ближайших платежах». 29 февраля в невисокосный год
  отмечается 28-го.

Календарь телефона (Ещё → «Календарь телефона», свёрнуто по умолчанию)
  Приложение не может напоминать, пока закрыто. Поэтому можно создать
  файл календаря (.ics) и добавить его в календарь телефона: напоминания
  сделает сам телефон.
  В файл можно включить: дни рождения (каждый год), дела (и обычные, и
  со временем — бывшие «события», с повторами), платежи по долгам по
  графику (ежемесячно; для 29–31 числа берётся последний день месяца),
  планы со сроком, ожидаемые возвраты долгов, сроки проектов, привычки
  (ежедневное напоминание в выбранное время, по выбранным дням недели).
  «Дела» включены по умолчанию — раньше это делали «события».
  Напоминания: для дел со временем — в момент начала, за 15 минут, за
  час или за день; для дат без времени — в день, накануне и в день, за
  неделю, накануне и в день (всегда в 9:00). Суммы в названиях можно
  отключить. Заметки и идеи подарков по умолчанию в файл НЕ попадают:
  если календарь общий, их увидят другие; включите, только если уверены.
  Прошедшие разовые дела и планы не экспортируются; у повторяющегося
  дела, если оно застряло на старой дате, берётся ближайшая будущая (по
  правилу повтора), сама запись при этом не меняется.
  Повторный импорт того же файла обычно обновляет записи, а не
  дублирует, но не все календари так делают.
  Как добавить файл:
    iPhone — сохраните в «Файлы», нажмите на файл, «Добавить все».
    Android — попробуйте открыть файл в календарном приложении: если
    оно принимает такие файлы, предложит добавить события. В справке
    Google импорт файлов описан для компьютера (calendar.google.com →
    Настройки → Импорт и экспорт), в приложении на телефоне он может
    быть недоступен. Надёжный способ на телефоне — добавлять по одному
    кнопкой «В Google Календарь» на странице дня рождения и в карточке
    события (откроется форма события, уже заполненная; напоминание
    выбирается там же).
  Напоминания из файла берут не все календари. Если календарь их
  игнорирует, задайте уведомления по умолчанию в настройках календаря,
  в который импортировали события (для событий на весь день удобно
  «накануне в 9:00»). Лучше импортировать в отдельный календарь.
  Время событий записано «как на часах» (без часового пояса) и
  подстраивается под пояс календаря.

Лимиты
  Ещё → Лимиты. «Обычные» лимиты действуют во все месяцы. На
  конкретный месяц (в том числе заранее, на 6 месяцев вперёд) можно
  задать свои: серое число в поле — обычный лимит, пустое поле — как
  обычно, 0 — «в этом месяце без лимита». Свои лимиты можно скопировать
  на следующий месяц или сбросить месяц к обычным.
  Лимиты мягкие: записи не блокируются. При вводе траты форма
  показывает, сколько останется или на сколько будет превышение; после
  сохранения появляется предупреждение, а на «Обзоре» — блок «Лимиты на
  месяц» и красная плашка, если что-то превышено.

Долги и цели (Деньги → «Долги/цели»)
  Долг: ипотека, кредит или кредитная карта. При создании укажите
  остаток из приложения банка. По желанию: ставку, ежемесячный платёж,
  день платежа, для карты — кредитный лимит.
  Платёж: запись типа «Долг». Вносится сумма платежа целиком и «из них
  проценты и комиссии». Остаток долга уменьшается только на основную
  часть, проценты попадают в расходы (категория «Проценты по долгам»).
  Можно ввести остаток после платежа из банка — проценты посчитаются сами.
  Кредитка как источник оплаты: при внесении расхода выберите «Чем
  оплачено». Трата попадёт в категорию и в лимиты, долг по карте вырастет,
  а свободные деньги не уменьшатся. Погашение карты вносится платежом.
  Сверка остатка: если остаток в банке отличается от записей, введите
  цифру банка, приложение внесёт поправку (её можно отменить).
  Цель: нужная сумма, уже накопленное, срок. Взносы вносятся записью
  «Цель» (можно и снимать). Показано, сколько осталось накопить и
  сколько откладывать в месяц.
  Если у долга указаны платёж и день платежа, ближайшие платежи видны на
  «Обзоре» в списке по датам.

Мне должны (Деньги → «Долги/цели»)
  Кто вам должен, сколько и до какого срока (срок необязателен).
  «Дал деньги сейчас»: деньги уходят из баланса на дату выдачи, но это
  не расход. «Уже должны»: деньги ушли раньше, баланс не трогается,
  приложение только помнит сумму.
  «Получил» (можно частично): деньги возвращаются в баланс, но это не
  доход. Остаток уменьшается, при нуле карточка уходит в «Возвращённые».
  «Дал ещё» увеличивает долг.
  Пока деньги не вернули, они в баланс на сегодня не входят. Ожидаемые
  возвраты видны в «Ближайших платежах» по сроку (без срока — в блоке
  «Без срока») и учитываются в строке «После всех платежей и планов».
  В месяце выданные деньги показаны отдельным сегментом «Дано в долг».

Быстрый ввод трат
  На «Сегодня» (и наверху «Операций») переключатель «Дело / Трата».
  В режиме «Трата» впишите, например, «кофе 250» и нажмите Enter: сумма
  берётся из последнего числа, остальное становится названием. Примеры:
  «такси 1,5к» (1 500), «продукты 1 200р», «+50 000 зарплата» (доход).
  Категория подбирается сама: по вашей истории (одинаковые названия),
  затем по словам («кофе», «такси», «аптека»…) и названию категории. Её
  можно поменять одним нажатием в подсказке под строкой. После сохранения
  внизу появляется «Отменить».
  Частые траты (одинаковые название, сумма и категория, не меньше двух
  раз за четыре месяца) показываются кнопками: одно нажатие добавляет
  такую же трату на сегодня.
  Полная форма расхода: сумма, категория (кнопки с самыми частыми
  сверху; «Ещё…» показывает остальные), название, дата («Сегодня» /
  «Вчера» или любая). Теги, заметка и магазин спрятаны в «Подробнее».
  Так же устроены остальные формы: сверху главное, остальное в «Подробнее».

Быстрые действия
  «Оплачено» / «Получено»: кнопка под строкой плана (на «Сегодня», в
  «Обзоре» и в «Планах») сразу вносит запись СЕГОДНЯШНИМ числом и
  закрывает план — независимо от того, какая дата стояла в плане (раньше
  или позже сегодня); повторяющийся план переходит на следующую дату.
  Для платежей по долгам такой кнопки нет: их вносят через форму, чтобы
  проверить проценты. Повторяющиеся планы без автовнесения тоже
  открывают форму: сумма (например, коммуналка) может меняться.
  Разбор слов. В строке «Дело» (на «Сегодня», в «Делах» и в Календаре
  на выбранный день): «вчера», «позавчера», «завтра», «послезавтра»,
  «через 3 дня», «через неделю», «в пятницу», «20.10», «20 октября»,
  «каждый день / неделю / месяц / год», «каждую пятницу», «#проект»,
  «@категория» (см. «Категории дел») и время — «15:30», «в 9 вечера»,
  «в 15 часов» («врач 15:30» превратится в дело с временем — то, что
  раньше было событием). В календаре дата по умолчанию — открытый
  день, а не сегодня.
  Те же слова про дату (кроме времени и повтора) понимает и строка
  быстрого ввода трат: «кофе вчера 250», «такси в пятницу 400»,
  «продукты 20.10 1200» — сумма ищется в тексте уже без даты, так что
  число из даты в неё не попадёт. Если дата распознана, а суммы нет,
  подсказка попросит её дописать и покажет, какую дату поняла.
  Под строкой везде показывается, как понято.
  «Повторить» в форме расхода или дохода создаёт копию на сегодня.
  «Сохранить и ещё» в новой записи сохраняет её и открывает следующую с
  той же датой.
  «Отменить»: удаление, «Перенести на завтра», отмена плана, сброс
  лимитов месяца, удаление тега и быстрое добавление выполняются сразу.
  Внизу семь секунд можно нажать «Отменить», и всё вернётся, в том числе
  шаги удалённого проекта.
  Плавающая кнопка «＋» внизу справа не дублирует кнопки самого экрана:
  на дне в календаре, в списке дней рождения, проектов и привычек её
  нет — там уже есть своя «＋» на месте. Она остаётся там, где даёт
  что-то ещё сверх этого: например, «Шаг» внутри открытого проекта или
  полная форма подарка на странице дня рождения.

Регулярные платежи и доходы (Деньги → Планы)
  В форме плана выберите «Каждый месяц / неделю / год». Пока включено
  «Вносить в день платежа автоматически», приложение само создаёт запись
  в день платежа (в том числе за дни, когда приложение не открывали:
  оно догоняет при запуске). Отключите, если сумма меняется (коммуналка):
  тогда платёж ждёт вас в «Ближайших платежах», а «Провести» вносит его и
  сдвигает план на следующую дату. «Отменить» останавливает серию.
  Ближайшие повторения (на три месяца) видны в прогнозе баланса.

Категории: значки и графики
  У категорий есть значки (в «Ещё → Категории» можно вставить свой
  эмодзи). На «Обзоре» расходы показаны кольцом по категориям, внизу —
  «Динамика»: доходы и расходы за шесть месяцев с текущим месяцем,
  выделенным цветом. Блок появляется, только когда есть хоть одна
  запись; стрелками ‹ › можно пролистать назад, если записи есть за
  более ранний период — вперёд дальше настоящего текущего месяца
  пролистать нельзя, там ещё нет данных. Это отдельная пролистка, она
  не связана с месяцем, открытым в «Обзоре» и «Операциях».

Как считаются цифры
  Расходы = траты (своими деньгами и кредиткой) + проценты по долгам.
  Погашение основного долга, взносы в цели и деньги, данные в долг,
  расходами не считаются, они показаны отдельно. «Свободные деньги» —
  то, что реально лежит у вас: покупки кредиткой их не уменьшают,
  платежи по долгам и взносы в цели уменьшают. Прогноз срока закрытия
  долга приблизительный: он считает ставку равномерно по месяцам и не
  знает о досрочных платежах и изменениях условий. Точные цифры — в
  графике платежей банка.

Баланс и ближайшие платежи
  Самая верхняя строка «Обзора» — свободные деньги на сегодня. Записи,
  внесённые на будущие даты, в него не входят.
  Ниже раздел «Ближайшие платежи»: планы, платежи по графику долгов и
  записи на будущие даты списком по датам, под каждой строкой — баланс
  после неё. Планам можно задавать срок (примерно).

Кнопка «Назад» на телефоне
  Если открыто окно (запись, платёж, долг, дело, событие), «Назад»
  закрывает его; на странице проекта, человека или привычки —
  возвращает к списку. Если ничего не открыто, приложение остаётся на текущем
  разделе и просит нажать «Назад» ещё раз; выход происходит по второму
  нажатию в течение двух секунд. Работает в установленном приложении и
  в браузере на телефоне; на компьютере кнопка «Назад» браузера не
  перехватывается.
