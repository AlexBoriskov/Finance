МОИ ФИНАНСЫ — приложение для телефона
=====================================

Что внутри
  index.html               — само приложение (один файл)
  manifest.webmanifest     — описание для установки на экран «Домой»
  sw.js                    — работа без интернета и обновление версий
  icon-*.png, apple-touch-icon.png — иконки

Как поставить на телефон
  Приложение нужно открыть по ссылке (https). Из файла напрямую оно
  тоже запускается, но браузер может очистить данные, а на экран
  «Домой» такое не устанавливается.

  1. Распакуйте архив и выложите файлы на бесплатный хостинг
     (GitHub Pages: репозиторий → uploading an existing file →
     перетащить файлы → Commit changes → Settings → Pages →
     Deploy from a branch → main / root).
  2. Откройте ссылку на телефоне.
  3. Android (Chrome): меню ⋮ → «Установить приложение».
     iPhone (Safari): «Поделиться» → «На экран Домой».

Как обновить приложение после новой версии
  1. Распакуйте новый архив.
  2. В репозитории на GitHub: Add file → Upload files → перетащите ВСЕ
     файлы (обязательно index.html и sw.js) → Commit changes.
     Файлы с теми же именами заменятся.
  3. Подождите минуту-две и откройте приложение на телефоне. Новая
     версия подхватится сама, при необходимости закройте и откройте
     приложение ещё раз.
  Данные при этом не пропадают: они лежат в телефоне, а не на сайте.

Где хранятся данные
  В localStorage браузера на этом устройстве. Никуда не отправляются.
  Данные привязаны к адресу сайта и к браузеру: если сменить адрес или
  браузер, они не перенесутся сами — сделайте копию (Настройки →
  Данные → Сохранить копию) и восстановите её на новом месте.
  Делайте копию раз в месяц: браузер может очистить память сайта.
  Приложение напомнит.

Лимиты
  Настройки → Категории расходов: справа от названия поле «Лимит» на
  месяц. Общий лимит расходов — в блоке «Основное».
  Лимиты мягкие: записи не блокируются. При вводе траты форма
  показывает, сколько останется или на сколько будет превышение; после
  сохранения появляется предупреждение, а на «Обзоре» — блок «Лимиты на
  месяц» и красная плашка, если что-то превышено.

Долги и цели (вкладка «Долги/цели»)
  Долг: ипотека, кредит или кредитная карта. При создании укажите
  остаток из приложения банка. По желанию: ставку, ежемесячный платёж,
  день платежа, для карты — кредитный лимит.
  Платёж: запись типа «Долг». Вносится сумма платежа целиком и «из них
  проценты и комиссии». Остаток долга уменьшается только на основную
  часть, проценты попадают в расходы (категория «Проценты по долгам»).
  Можно ввести остаток после платежа из банка — проценты посчитаются сами.
  Кредитка как источник оплаты: при внесении расхода выберите «Чем
  оплачено». Трата попадёт в категорию и в лимиты, долг по карте вырастет,
  а свободные деньги не уменьшатся. Погашение карты вносится платежом.
  Сверка остатка: если остаток в банке отличается от записей, введите
  цифру банка, приложение внесёт поправку (её можно отменить).
  Цель: нужная сумма, уже накопленное, срок. Взносы вносятся записью
  «Цель» (можно и снимать). Показано, сколько осталось накопить и
  сколько откладывать в месяц.
  Если у долга указаны платёж и день платежа, ближайшие платежи видны на
  «Обзоре» в списке по датам.

Как считаются цифры
  Расходы = траты (своими деньгами и кредиткой) + проценты по долгам.
  Погашение основного долга и взносы в цели расходами не считаются, они
  показаны отдельно. «Свободные деньги» — то, что реально лежит у вас:
  покупки кредиткой их не уменьшают, платежи по долгам и взносы в цели
  уменьшают. Прогноз срока закрытия долга приблизительный: он считает
  ставку равномерно по месяцам и не знает о досрочных платежах и
  изменениях условий. Точные цифры — в графике платежей банка.

Мне должны (вкладка «Долги/цели»)
  Кто вам должен, сколько и до какого срока (срок необязателен).
  «Дал деньги сейчас»: деньги уходят из баланса на дату выдачи, но это
  не расход. «Уже должны»: деньги ушли раньше, баланс не трогается,
  приложение только помнит сумму.
  «Получил» (можно частично): деньги возвращаются в баланс, но это не
  доход. Остаток уменьшается, при нуле карточка уходит в «Возвращённые».
  «Дал ещё» увеличивает долг.
  Пока деньги не вернули, они в баланс на сегодня не входят. Ожидаемые
  возвраты видны в «Ближайших платежах» по сроку (без срока — в блоке
  «Без срока») и учитываются в строке «После всех платежей и планов».
  В месяце выданные деньги показаны отдельным сегментом «Дано в долг».

Баланс и ближайшие платежи
  Самая верхняя строка «Обзора» — свободные деньги на сегодня. Записи,
  внесённые на будущие даты, в него не входят.
  Ниже раздел «Ближайшие платежи»: планы, платежи по графику долгов и
  записи на будущие даты списком по датам, под каждой строкой — баланс
  после неё. Планам можно задавать срок (примерно).

Кнопка «Назад» на телефоне
  Если открыто окно (запись, платёж, долг), «Назад» закрывает его. Если
  ничего не открыто, приложение остаётся на текущем разделе и просит
  нажать «Назад» ещё раз; выход происходит по второму нажатию в течение
  двух секунд. Работает в установленном приложении и в браузере на
  телефоне; на компьютере кнопка «Назад» браузера не перехватывается.
