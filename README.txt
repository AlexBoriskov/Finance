МОИ ФИНАНСЫ — приложение для телефона
=====================================

Что внутри
  index.html               — само приложение (один файл)
  manifest.webmanifest     — описание для установки на экран «Домой»
  sw.js                    — работа без интернета
  icon-*.png, apple-touch-icon.png — иконки

Как поставить на телефон (5 минут)
  Приложение нужно открыть по ссылке (https). Из файла напрямую оно
  тоже запускается, но браузер может очистить данные, а на экран
  «Домой» такое не устанавливается.

  1. Выложите папку на любой бесплатный статический хостинг:
     GitHub Pages, Cloudflare Pages, Netlify и т. п.
     (GitHub Pages: новый репозиторий → загрузить все файлы из архива →
     Settings → Pages → Deploy from a branch → main / root.)
  2. Откройте полученную ссылку на телефоне.
  3. iPhone (Safari): «Поделиться» → «На экран Домой».
     Android (Chrome): меню ⋮ → «Установить приложение».

  Ссылку увидит любой, кому вы её дадите, но ваших данных на сайте нет:
  они хранятся только в памяти браузера на вашем устройстве.

Где хранятся данные
  В localStorage браузера на этом устройстве. Никуда не отправляются.
  Данные привязаны к адресу сайта: если вы поменяете адрес, они не
  перенесутся сами — сделайте копию (Настройки → Данные → Сохранить
  копию) и восстановите её на новом месте.
  Копия открывается и в предыдущей версии приложения (та, что внутри
  Claude), и наоборот.
  Делайте копию раз в месяц: браузер может очистить память сайта,
  особенно в Safari, если приложение не установлено на экран «Домой».

Сканирование чеков
  Нужен ключ API Anthropic:
    1. console.anthropic.com → API keys → Create key.
    2. Пополните баланс (оплата по факту использования, отдельно от
       подписки Claude).
    3. Вставьте ключ в Настройки → Распознавание чеков.
  Ключ хранится только на вашем устройстве и в копии данных не попадает.
  Фото уходит с телефона напрямую в Anthropic и нигде не сохраняется.
  Агент читает чек, сверяет сумму позиций с итогом и, если не сошлось,
  сам перепроверяет фото один раз.
  Не вставляйте ключ на чужих устройствах.
